# 토스 미국주식 급등주 모바일 웹앱

휴대폰에 Python을 설치하지 않고, 서버에 한 번 배포한 뒤
Chrome/Samsung Internet에서 접속하는 방식입니다.

## 기능
- 최대 20개 미국주식 종목 스캔
- 당일 상승률
- 거래량
- 근사 RVOL
- VWAP
- 조건 충족 여부
- -3% 손절가
- +5% 1차 익절가
- +10% 2차 익절가
- 모바일 화면 최적화
- 홈 화면 추가(PWA 형태)

## 가장 쉬운 배포 방법: Render

1. GitHub에 새 저장소를 만듭니다.
2. 이 압축파일 안의 파일을 모두 업로드합니다.
3. Render에서 새 Web Service를 만듭니다.
4. GitHub 저장소를 연결합니다.
5. Build Command:
   pip install -r requirements.txt
6. Start Command:
   gunicorn app:app
7. 배포가 끝나면 Render가 주소를 하나 줍니다.
8. 그 주소를 휴대폰 Chrome에서 열면 됩니다.

## 사용법
- 종목코드 입력: AAPL, NVDA, TSLA 등
- "지금 스캔" 버튼
- 조건 충족 종목은 "★ 조건 충족" 표시
- 손절/익절 가격 자동 계산

## 기본 조건
- 상승률 +10% 이상
- RVOL 3배 이상
- 거래량 100만주 이상
- VWAP 위

화면에서 숫자를 바로 바꿀 수 있습니다.

## 홈 화면에 앱처럼 추가
Android Chrome:
1. 웹앱 주소 접속
2. 우측 상단 메뉴(⋮)
3. "홈 화면에 추가"
4. 이후 앱 아이콘처럼 실행 가능

## 중요
이 웹앱은 토스증권 주문 API에 연결되지 않습니다.
토스 앱에서 주문은 직접 해야 합니다.

시세는 yfinance 공개 데이터를 사용하므로 지연/누락 가능성이 있습니다.
특히 프리마켓/애프터마켓/급등주는 토스 앱의 실제 현재가와 호가를 반드시 확인하세요.
